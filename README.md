# 📊 Sales Insight Dashboard | Power BI

An interactive **Sales Insight Dashboard** built using **Power BI** to analyze sales performance and generate actionable business insights. This project demonstrates data cleaning, data modeling, DAX calculations, and interactive dashboard design to support data-driven decision-making.

---

## 🚀 Features

- 📈 Interactive KPI cards for sales performance
- 💳 Payment Type Analysis (Cash, Card, Phone Pay)
- 🌍 Zone-wise Sales Performance Analysis
- 📅 Dynamic Year, Month, and Day Slicers
- 📊 Interactive Charts and Visualizations
- ⚡ DAX Measures for business metrics
- 🔄 Data Modeling with relationships
- 🎯 User-friendly dashboard for business insights

---

## 🛠️ Tech Stack

- **Power BI**
- **DAX (Data Analysis Expressions)**
- **Power Query**
- **Data Modeling**
- **Data Cleaning & Transformation**
- **Data Visualization**

---

## 📈 Dashboard Insights

The dashboard provides insights into:

- Total Sales Amount
- Total Billing Locations
- Total Billing Records
- Sales Representative Count
- Payment Type Distribution
- Zone-wise Sales Performance
- Year-wise Sales Analysis
- Month-wise and Day-wise Filtering

---

## 🎯 Project Objective

The objective of this project is to transform raw sales data into meaningful business insights by developing an interactive dashboard. It helps stakeholders monitor sales performance, analyze payment trends, compare regional performance, and make informed business decisions.
